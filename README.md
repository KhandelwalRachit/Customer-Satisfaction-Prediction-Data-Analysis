# Customer-Satisfaction-Prediction-Data-Analysis
## 📌 Project Overview
This project analyzes customer support tickets and builds a machine learning model to predict customer satisfaction ratings.

## 📊 Dataset
The dataset includes:
- Customer demographics
- Ticket type
- Ticket channel
- Product purchased
- Response time
- Resolution time
- Customer satisfaction rating

## 🛠 Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- WordCloud

## 🔍 Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. NLP analysis of ticket descriptions
4. Feature Engineering
5. Machine Learning Model

## 🤖 Machine Learning Model
Random Forest Classifier

## 📈 Visualizations
- Customer age distribution
- Ticket channel analysis
- Satisfaction rating distribution
- Word cloud of customer issues
- Confusion matrix

## 🎯 Key Insights
- Ticket priority significantly affects customer satisfaction.
- Certain products generate more customer complaints.
